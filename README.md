# Bug Simulator

Interactive bug simulation game built in Unity, showcasing ecosystem behavior and emergent AI.

## Overview
Bug Simulator is a Unity game project that models realistic bug behavior and ecosystem dynamics. The simulation features multiple bug species with AI-driven behaviors, environmental interactions, and emergent ecological patterns. The project demonstrates game development, physics-based simulation, and intelligent agent design.

## What's included
- `Assets/Scenes/` — main game scenes and levels.
- `Assets/Challenges/` — challenge modes and gameplay scenarios.
- `Assets/Samples/` — example scenes and demonstrations.
- `Assets/Settings/` — graphics and project settings.
- `Assets/TutorialInfo/` — tutorial content and documentation.
- `Packages/` — Unity dependencies and plugins.
- `ProjectSettings/` — Unity project configuration.

## Quick start
1. Clone the repository and open in Unity (2021 LTS or later recommended).

2. Open the main scene from `Assets/Scenes/`.

3. Press **Play** in the Unity Editor to run the simulation.

4. Explore different challenges in `Assets/Challenges/` for specific gameplay scenarios.

## Features
- Multiple bug species with distinct AI behaviors
- Environmental physics and resource management
- Emergent ecosystem dynamics
- Interactive challenge modes
- Visual simulation and debugging tools
